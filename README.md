# odin-recipes
Built a multi-page recipe website featuring a homepage and three linked recipes. Each recipe page includes a photo, description, ingredients, preparation steps, and navigation back to the homepage. Developed practical skills in HTML, file organization, relative paths, browser testing, and Git version control.
## What I built and learned
(recipe website and debugging work)
- Built a recipe website with a homepage and three pages: lasagna, shrimp pasta, and tacos.
- Designed and added photos, descriptions, ingredients, preparation steps, and navigation links.
- Tested the pages in a browser and fixed missing image tags and broken image paths.
- Practiced HTML, file organization, VS Code, Ubuntu, Git, and GitHub.
